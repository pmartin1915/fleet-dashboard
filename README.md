# Dispatcher Fleet Dashboard

Static frontend for the budget-dispatcher fleet monitor. Reads from a public GitHub gist; no backend.

- **Live dashboard:** GitHub Pages on this repo (see Settings → Pages for the URL).
- **Source of truth:** the dashboard HTML is generated/edited in the private parent repo at `docs/fleet-dashboard.html` and published here for hosting only.
- **Data:** fetched client-side from gist `655d02ce43b293cacdf333a301b63bbf`.

No secrets, no logic, no state — just a renderer.
